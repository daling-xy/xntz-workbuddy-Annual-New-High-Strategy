# 人工最终股票池 · 跟踪方案

## 目的

用户每天会给出“模型 + 人工判断”合并后的**最终股票池**。把它记录下来，长期回答三个问题：

1. 人工池与 v3 / v3.1 名单的差异在哪里（哪些被模型门槛挡掉、哪些是模型没选到的）；
2. 人工池的 20 日结果是否显著好于 v3 名单（人工判断有没有超额价值）；
3. 被模型挡掉、但人工选中的票，是否说明某条门槛太严（尤其是波动率门）。

## 记录方式

每天收盘后（或次日盘前）把股票代码发给我，我运行：

```powershell
python v3/human_picks.py --date 2026-11-16 300760 603233 600018 601000
```

自动记录到 `output/track/human_picks.csv`，字段包括：

- 当日特征：收盘、成交额、prox、vol20、volratio、ret10、ret60、turn30、z10、是否 close>MA60、MA5>MA20；
- 归属：是否在当日 v3 名单、v3.1 名单；
- 结果：20 个交易日后自动回填 fwd20、是否大亏（≤−20%）。

## 能学到什么、不能学到什么

**能学：**
- 人工池相对模型名单的**增量价值**（fwd20、大亏率）；
- 被门槛挡掉的票的**事后表现**——如果反复证明“被挡的反而更好”，就是门槛太严的直接证据；
- 哪些特征在人工选择里反复出现（prox/波动/趋势的组合），可形成候选假设。

**不能学 / 要小心：**
- 每天只有几只，样本小；60 个交易日约 200 条，统计功效有限；
- 人工选择可能包含新闻、题材、主观偏好等**数据外信息**，不能指望用现有特征复现；
- 只看“选中”的票无法判断“为什么没选其他票”——需要把 v3 名单、v3.1 名单当作**未选中样本**一起分析；
- 从人工池里总结出的任何规律，都只是**假设**，必须经过双向样本外验证才能进模型，否则就是过拟合。

## 分析计划（满 60 个交易日 / ≥40 条结果后）

1. 人工池 vs v3 名单 vs v3.1 名单：fwd20、大亏率、胜率；
2. 人工池拆分：在模型名单内 vs 不在名单内（被门槛挡掉）；
   - 若“不在名单内”的那部分显著更好 → 对应门槛（大概率是波动率门）偏严，进入假设检验；
3. 对被挡掉的票做门槛反事实：按当时 volratio/vol20 分档，看收益是否单调；
4. 所有假设走一遍“双向样本外 + 扣成本”，通过才改 v3。

## 首次记录（2026-11-16）的观察

人工池：迈瑞医疗、大参林、上港集团、唐山港。

| 代码 | 名称 | 模型归属 | 被哪条门槛挡住 |
|---|---|---|---|
| 601000 | 唐山港 | **v3 + v3.1 都在** | 未被挡 |
| 300760 | 迈瑞医疗 | 都不在 | **volratio=1.20 > 1.0**（波动率相对自身放大） |
| 600018 | 上港集团 | 都不在 | **volratio=1.59 > 1.0** |
| 603233 | 大参林 | 都不在 | **vol20=50.9% > 35%**，且 volratio=1.51 |

→ 4 只里 3 只倒在波动率门上，正好对应“波动率相对放大该不该挡”这个还没定论的问题。它们的 20 日结果会是有价值的证据。
