# v3.1 候选 · 平行纸上跟踪方案

## 为什么要跟踪而不是直接切换

v3.1 候选（R1T2）在双向样本外里两个方向都是正的（+0.31pp / +0.20pp），但只有一边显著；
留一年检验中只赢 4/8 年、平均 +0.08pp，增益集中在 2020–2021，2019/2024 反而更差。
结论：**证据不足以直接替换生产版**，先平行跟踪。

## 版本差异（相对 v3 只改两条）

| 条件 | v3（生产） | v3.1（候选） |
|---|---|---|
| 短期涨幅 | `ret10 <= 8%` | `z10 = ret10/(日波动率×√10) <= 2.0` |
| 中期趋势 | `ret60 >= 0` | `close > MA60 且 MA5 > MA20` |

宇宙、清洗、波动率门（volratio≤1.0 且 vol20≤35%）、prox≥0.90、turn30≤5%、排序与分档全部相同。

## 每日流程（一条命令，两版同时出）

```powershell
python run_daily.py --fresh --asof 0
```

- v3 生产名单 → `output/v3/daily_rank_v3_YYYYMMDD.csv`
- v3.1 候选名单 → `output/v31/daily_rank_v31_YYYYMMDD.csv`
- 两版名单自动写入 `output/track/picks.csv`（含档位/prox/代码/名称/当日收盘；20 日后自动回填收益）

单独回填/汇总：`python v3/paper_track.py`

## 评估口径

- 收益：**收盘→20 个交易日后收盘**（前复权），毛收益；汇总时按扣 0.2% 成本看；
- 大亏：20 日收益 ≤ −20%；
- 同时看：名单数量、档位分布、A 档占比。

## 决策规则（先写死，避免事后找理由）

跟踪满 **60 个交易日** 且每版至少 **40 条** 20 日结果后判断：

1. 若 `v3.1 净fwd20均值 − v3 ≥ +0.10pp`，且 `v3.1 大亏率 ≤ v3 大亏率 + 0.2pp`，且最近 3 个月中至少 2 个月方向一致 → **切换为 v3.1**（改 `daily_rank_v3.py` 两行）；
2. 若 `v3.1 − v3 ≤ 0` 或大亏明显更高 → **放弃 v3.1**，删除候选脚本；
3. 其余情况 → 延长跟踪，不切换。

> 注意：名单很少（日均 3–5 只），60 个交易日约 200 条/版，统计功效有限；结论以"方向一致 + 幅度"为准，不做单日解读。
