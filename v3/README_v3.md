# 年度新高策略 v3 · 推倒重来版

> 定版日期：2026-11-13 ｜ 状态：纸上跟踪（未上实盘）
> 与 v2.6 的关系：**独立的一版**，不复用 VCP 的 ct/C/H/F 门，也不是 v2.6 的参数微调。
> 代码入口：`v3/daily_rank_v3.py` ｜ 证据脚本：`v3/evidence/` ｜ 示例输出：`v3/examples/`

---

## 1. 一句话逻辑

> 在**低波动、筹码稳定、中期向上**的股票里，买**贴近年高**的那一批；越贴年高越靠前。

不是追突破、不追高、不炒题材——只解决“选票”这一层。

## 2. 与 v2.6 的区别

| 维度 | v2.6（旧） | **v3（本版）** |
|---|---|---|
| 流动性门 | 30 日日均成交额 ≥2 亿 | **当日成交额 ≥2 亿** |
| 波动率 | 无独立波动率门（只靠 VCP 箱宽） | **vol20 ≤1.0×自身一年均值 且 ≤35%** |
| 形态门 | VCP（w10/ct/w30）+ R/C/H/F | **全部撤下** |
| 条件 | 6+ 道门 + 行业黑名单 | **4 条**：prox / ret10 / turn30 / ret60 |
| 排序 | 67 项打分 | **只用 prox**（唯一过双向样本外的特征） |
| 通道 | 主池 + 坑后平台卫星池 | 单通道（后续再验证是否加） |

## 3. 选股结构（四层）

### 第 0 层：清洗
- 剔除 ST / 名称含“退”
- 剔除 9 类行业：银行Ⅱ、基础建设、房屋建设Ⅱ、专业工程、工程咨询服务Ⅱ、铁路公路、物流、航空机场、通信服务（东财 board 口径）

### 第 1 层：宇宙（波动率门）
| 条件 | 定义 | 阈值 | 为什么 |
|---|---|---|---|
| 当日成交额 | 当日 amount | ≥2 亿 | 流动性 |
| vol20 | 近 20 日收益标准差 ×√252（20 日年化波动率） | **≤1.0×自身过去一年 vol20 均值** | 挡“波动率相对自身突然放大”；天然高波票只要处在自己的常态即可进 |
| vol20 绝对上限 | 同上 | **≤35%** | 保险丝：>40% 收益转平、>50% 大亏率 5% |

> 25%/30% 的绝对上限在数据上偏低（会把 30-35% 这一档最好的收益切掉）；40% 又偏松。「相对 + 35%」是扫描后的折中。

### 第 2 层：条件（四条）
| 指标 | 算法 | 阈值 | 作用 |
|---|---|---|---|
| **prox** | 今收 ÷ 近 250 日最高收盘 | **≥0.90** | 贴近年高（52 周高点效应） |
| **ret10** | 近 10 个交易日涨幅 | **≤8%** | 防追高（A 股短期反转强） |
| **turn30** | 近 30 日平均换手率 | **≤5%** | 避交易过热；换手最高档 fwd20 −0.25%、大亏 1.0% |
| **ret60** | 近 60 个交易日涨幅 | **≥0** | 中期趋势不能向下；只设下限、不设上限 |

### 第 3 层：排序
- **prox**（连续值）作为唯一排序分；A ≥0.98 / B ≥0.95 / C ≥0.90，**不设名额**（每天数量随信号变化）。
- 为什么只用 prox：数据挖掘式特征选择（逐特征 IC + 分年同号）在两半样本上选出方向矛盾的特征，**测试集 IC ≈0**，不可用；只有 prox 两方向都同号、且测试集 IC 0.030–0.041。

## 4. 验证结果（2019-01 ~ 2026-11-04，learn 全A数据）

### 4.1 底座条件（双向样本外，fwd20 超额，扣 0.2% 成本）
| 训练→测试 | 训练年挑出的条件 | 测试 fwd20 | 测试大亏 |
|---|---|---|---|
| 19-22 → 23-26 | prox≥0.90 + ret60≥0 | **+0.70%** | 0.7% |
| 23-26 → 19-22 | prox≥0.95 + ret10≤8% + turn≤5% | **+1.54%** | 1.1% |

### 4.2 排序（prox）双向样本外
| 切分 | 测试 IC | 测试 A 档 | 测试 C 档 |
|---|---|---|---|
| 19-22 → 23-26 | 0.030（t 3.8） | +1.02% | +0.91% |
| 23-26 → 19-22 | 0.041（t 3.7） | +2.06% | +1.22% |

### 4.3 波动率门对比（宇宙层，fwd20 扣成本）
| 组合 | 日均只数 | fwd20 | 大亏 |
|---|---|---|---|
| 1.0× & ≤35% | 230 | +0.10% | 0.6% |
| 1.2× & ≤35% | 263 | +0.09% | 0.7% |
| 1.0× & ≤40% | 288 | +0.09% | 0.8% |
| 无相对门 & ≤35% | 314 | +0.02% | 0.8% |

## 5. 每日用法

```bash
# 1) 收盘后先刷新行情（仓库根目录）
python run_daily.py --fresh --asof 0

# 2) 跑 v3 选股
python v3/daily_rank_v3.py
# 输出：output/v3/daily_rank_v3_YYYYMMDD.csv
```

输出字段：date / tier / prox / code / name / board / industry / anchor / close / chg / vol20 / volratio / ret10 / ret60 / turn30 / amt_yi

## 6. 已知局限

1. **阈值仍是样本内选定**（分年一致性与双向样本外只降低了过拟合概率，不等于证明）；
2. **弱势市场名单会很少**（11-13 只有 4 只、A 档为空）——这是“贴近新高”条件的特性，不是 bug；
3. **排序增量有限**：2023-26 的 A/C 差只有 0.1–0.2pp，主要收益来自门槛后的池子；
4. 未计冲击成本；未做涨停不可买（仅当日不买涨停）；
5. 通道扩展（强势回踩/真突破等）未纳入，需单独过同样的双向样本外。
