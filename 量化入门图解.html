② beta：最会伪装的陷阱

如果你的票本身就比大盘敏感（β>1），那市场涨的时候它涨更多——这部分不是你的本事。

注意：上面的 β=1.66 是教学示意数字。真实回测里，下跌市深跌组（当前价/年高<0.70）的 β 中位数约 1.07，贴着年高的组约 0.89。差距真实存在，但没有示意里那么夸张。 下面讲算法本身。
最常见的误解：β 不是"分组之后算出来的"。
正确顺序是：① 每一只票【自己】先算出一个 β → ② 事后按别的条件分组 → ③ 只做一件事：数一数这组里 β 的中位数。
β 是股票的固有属性（就像它的市值一样），跟你怎么分组、用什么筛选条件完全无关。

先补最底层：Cov 和 Var 怎么算（3 天的最小例子，股票刚好是市场的 2 倍）

日市场 m股票 sm − m̄s − s̄(m−m̄)(s−s̄)(m−m̄)²
1+1%+2%+0.333+0.667+0.2220.111
2−1%−2%−1.667−3.333+5.5562.778
3+2%+4%+1.333+2.667+3.5561.778
Σm̄=0.667s̄=1.3339.3334.667

Var(m)（市场自己波动多大）= Σ(m−m̄)² ÷ (n−1) = 4.667 ÷ 2 = 2.333
Cov(r,m)（股票和市场一起动多少）= Σ(r−r̄)(m−m̄) ÷ (n−1) = 9.333 ÷ 2 = 4.667
β = Cov ÷ Var = 4.667 ÷ 2.333 = 2.00 —— 正好是 2 倍，符合设计。

口诀：Var 问"市场自己抖多狠"，Cov 问"这票跟着市场一起抖多少"，两者一除就是放大倍数 β。 注：除以 n−1 还是 n 无所谓，β 是比值，上下约掉了。

β 的定义（对市场基准做回归得到的斜率）：

β = Cov(股票日收益, 市场日收益) ÷ Var(市场日收益)

本项目的具体做法：用事件日之前 250 个交易日的日收益，对 等权全 A 日收益（不是沪深300）做滚动回归。

③ 为什么同一天的股票不能算"独立样本"

标准误公式 SE = 标准差 ÷ √样本数 要求样本互相独立。同一天入选的票面对同一个大盘，不独立。

每次抛硬币互不影响 → 真的是 30 个证据
共享同一个大盘 → 其实只有 1 个证据

④ 整簇重抽样：把"同一天"当成一个整体来抽

普通 bootstrap 逐条抽事件（错，破坏相关性）；整簇重抽样整天地抽（对，保留相关性）。

逐事件 bootstrap（错误做法）
整簇（按交易日）bootstrap（正确做法）
1000 次重抽样各自算出的「策略平均超额」分布 —— 每一次都是一个平行宇宙：
横轴 = 那次重抽样算出的平均超额，纵轴 = 出现次数。 分布越矮胖，说明这个策略的结果越不稳定。
这一步到底在干什么？我们手上只有一段真实历史，算出一个 +4.22%。 但真正想知道的是：如果历史重演一遍，这个数字会变成多少？
重抽样就是用现有数据自己造出一千个"平行历史"，看结果会散到什么程度。 所以 bootstrap 不是为了让 4.22% 更准，而是为了回答"4.22% 有多不可靠"。

④⁺ 整条流水线的顺序：重抽样到底发生在哪一步

最容易搞混的一点：「按年高分组」和「整簇重抽样」是两个完全不同阶段的动作，中间隔着好几步。 整簇重抽样抽的是交易日，跟年高分组毫无关系。

1原始 K 线5575 只票 × 2018 年至今，前复权
2生成事件表150.2 万行 = 一只票 × 一个日期；此时没有任何门槛
3给每个事件算 β用该票前 250 天日收益对市场回归
4给每个事件打周期标签UP / CHOP / DOWN
5套 mask（策略在这里）按 年高 / 箱宽 / 成交额 / 换手 挑子集
6算点估计这 N 个事件的 α 均值，比如 +3.46%
7整簇重抽样（重抽样在这里）按交易日有放回抽，一天里的事件同进同出
8得到 1000 个平行历史取 5% / 95% 分位 = 90% 置信区间
常见误解对照：
✗ "整簇 = 按 当前价/年高 分出来的组" —— 不对。年高分组发生在第 5 步（挑子集）， 抽的是事件；整簇重抽样发生在第 7 步（算完点估计之后），抽的是交易日。
✗ "对每个簇内都做一次随机有放回重抽样，算出 α 再比参数" —— 不对。 重抽样不改变点估计，它只用来估计"这个点估计有多不可靠"。比参数看的是第 6 步的 α 和 第 8 步的 CI，不是重抽样本身。
一句话：重抽样发生在「已经算出 +3.46% 之后」，目的是回答「这 +3.46% 有多不可靠」。
做法：把 1,725 个交易日当成 1,725 张卡片，有放回地抽 1,725 张（同一天可能被抽中多次）， 每次都用抽到的那些天的全部事件重算一遍 α 均值。重复 1000 次，就得到 1000 个"平行历史"的 α。

⑤ 怎么读置信区间："CI 含零"是什么意思

90% 置信区间 = 真实效果有 90% 概率落在这个范围里。跨过 0 就等于"数据分不清它是正是负"。

例子90% CI判读
本策略 UP 期[1.7, 7.1]显著为正 —— 能用
本策略 DOWN 期[1.4, 5.6]显著为正 —— 能用
下跌市放宽到 <0.70 的深跌股[−0.9, 1.0]含零 —— 不能当规律用
v1 参数在 DOWN 期[−4.8, −1.4]显著为负 —— 历史上是稳定亏的
口诀：区间整体在 0 的同一侧才算数；跨过 0 就当它不存在。

⑤⁺ 置信区间的底层原理：重复一千次，有多少次罩住真值

核心一句话：置信区间不是「真值有 95% 概率落在里面」，而是「用这套方法造区间，重复做 100 次，大约 95 次会罩住真值」。 真值是固定的，会动的是区间。

三步底层逻辑：
① 我们回测算出的 +3.46% 只是一次抽样的结果，换成另一段历史它会变。
② 如果「历史重演很多次」，每次算出的数会散开形成一个分布 —— 这叫抽样分布，它的宽度就是标准误 SE。
③ 于是 CI = 点估计 ± 1.96 × SE。SE 越小（样本越多 / 噪音越小），区间越窄；但覆盖率不变。

⑥ 为什么回归的斜率恰好等于 Cov ÷ Var（几何解释：投影）

把 250 天的收益想成 250 维空间里的两个向量。斜率 = 一个向量投影到另一个向量上的倍数。

一句话：β 就是「个股收益向量投影到市场收益向量上的倍数」；α 就是那个垂直于市场、市场永远解释不了的残差。
因为垂直，所以 α 和市场天生不相关 —— 这正是「α = 与市场无关的选股能力」这句话的几何来源。

⑥⁺ 不用向量也能懂：把斜率推导一遍（只要会二次函数）

上面的投影图看不懂没关系 —— 同一个结论用初中数学就能推出来，而且更朴素。

问题：有 250 天的数据，每天两个数 —— 市场涨了 m，这票涨了 r。 想找一个数 β，让"预测误差的平方和"最小：

S(β) = (r₁ − β·m₁)² + (r₂ − β·m₂)² + … = Σ(r − β·m)²

把它展开（就是完全平方公式）：

S(β) = Σr² − 2β·Σ(m·r) + β²·Σm²

这正好是一个关于 β 的开口向上的抛物线（a = Σm² > 0）。抛物线最低点在 β = −b/(2a)，也就是：

β = 2·Σ(m·r) / (2·Σm²) = Σ(m·r) / Σ(m²)

再把 m 和 r 各自减去平均值（这正是回归里"带截距 α"在做的事），于是：

Σ(m·r) → Σ(m−m̄)(r−r̄) = (n−1)·Cov(r,m)　　Σ(m²) → Σ(m−m̄)² = (n−1)·Var(m)
上下同时约掉 (n−1)：β = Cov(r,m) ÷ Var(m)

拿 3 天数字亲自验一遍：

天市场 m个股 r β=2.0 的误差β=2.5 的误差 β=3.0 的误差
第 1 天+1+2 2−2.0×1 = 0.02−2.5×1 = −0.52−3.0×1 = −1.0
第 2 天−2−5 −5+4.0 = −1.0−5+5.0 = 0.0−5+6.0 = +1.0
第 3 天+1+3 3−2.0 = +1.03−2.5 = +0.53−3.0 = 0.0
误差平方和 S(β) 2.000.50 ← 最小2.00
用公式算：Σ(m·r) = 1×2 + (−2)×(−5) + 1×3 = 15；Σ(m²) = 1+4+1 = 6； β = 15 ÷ 6 = 2.5 —— 和"试出来最小的是 2.5"完全一致。
所以「斜率 = Cov ÷ Var」不是巧合，它就是"让误差平方和最小的那个 β"。
上一节的向量投影图，是同一件事的另一种说法 —— 数学上完全等价，只是画图的人喜欢用几何语言。 你只要记住初中版本的推导就够了。
为什么偏要用"平方"而不是"绝对值"？① 平方处处可导，能直接解出顶点； ② 平方对大误差惩罚更重（错 2 个点算 4 倍，不是 2 倍），更符合"不想出现大偏差"的直觉； ③ 高斯当年证明过：如果噪声是正态分布，平方误差给出的就是最可信的估计。

⑧ Var / Cov / ρ / σ / β 五兄弟：谁是谁，多少算大

最容易搞混的一点：Cov（协方差）不是相关系数。相关系数 ρ 才是那个 −1 到 +1 的、没有单位的量； Cov 是它的"带单位原始版"。

量公式单位直觉
Var 方差 Var(X)=Σ(x−x̄)²/(n−1) 百分比平方 波动的"面积"，不直观，所以平时不直接看它
σ 标准差 σ=√Var(X) 百分比 说"波动多大"时用的就是这个
Cov 协方差 Cov(X,Y)=Σ(x−x̄)(y−ȳ)/(n−1) 百分比平方 "两个东西一起动"的强度，但带着单位，看不出大小
ρ 相关系数 ρ=Cov(X,Y)/(σ_X·σ_Y) 无单位，锁死 [−1,+1] 把 Cov 除以两个标准差"标准化"之后的版本 = 纯粹的"同步程度"
β β=Cov(r,m)/Var(m)=ρ×(σ_股/σ_市) 无单位，倍数 市场动 1%，这只票平均动百分之几
一句话串起来： σ 说自己抖得多厉害 → ρ 说跟市场同步得多紧 → β = ρ × (σ股 ÷ σ市) 把这两件事合成一个数："市场动 1%，我动几个点"。
注意 β 里没有 Cov 单独出现的位置是巧合 —— 因为 Cov 已经被拆成 ρ·σ股·σ市， 再除以 σ市²（也就是 Var），就消掉了一个 σ市，剩下 ρ×σ股/σ市。

所以"β 大"是什么意思？β=1.107（下跌市深跌组的水平）意味着市场涨 10% 它平均涨 11%，市场跌 10% 它平均跌 11%。 它不是能力，是杠杆。在下跌市里你去买 β=1.1 的深跌股，赚到的那点超额里，有 β 倍的市场反弹 —— 那不是你选出来的，是市场白送的。
反过来看我们最终纪律筛出来的那批：β 中位数只有 0.167 —— 几乎不跟市场走， 涨的 5.01% 里"应得"的只有 1.55%，剩下 +3.46% 才是真正挑出来的东西。

这两个词在策略文档里经常被混着用，但它们是两个不同的量。 下面三条价格路径，箱宽完全一样，走法却天差地别 —— 拖动看看。

看明白了吗：三条线的「最高价」和「最低价」完全一样，所以箱宽都是 15%。
但它们的日波动能差 3~5 倍 —— 因为箱宽只用了两个点（最高、最低）， 波动率用了全部 30 天的日收益。
