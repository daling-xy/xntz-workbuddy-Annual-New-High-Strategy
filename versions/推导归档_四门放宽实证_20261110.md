# 推导归档 · 四门放宽实证（2026-11-10）

## 0. 背景与假设

起因：11-09 实盘池（9 只全为防御型）与用户主观预期（百济神州、昭衍新药、国电电力）不符，
用户要求检验"能否放宽"。三只票全部倒在门①（距年高≤5%），百济另卡箱宽、昭衍另卡箱宽+换手。

四个待验假设：

| 假设 | 内容 | 动机 |
|---|---|---|
| H1 | prox_now 0.95 → 0.90 | 国电电力差 2.5pp 被拦 |
| H2 | width30 15% → 20% | 百济神州箱宽 18.8% 被拦 |
| H3 | turn30 6% → 7% | 昭衍新药换手 6.47% 被拦 |
| H4 | 删除 ret60≤19% 门 | 复核 10-29"风险门"结论 |

## 1. 方法（沿用既有纪律，两处防坑）

- **样本**：events_fixed.pkl，1,502,209 行 / 5,321 只 / 1,725 交易日（2019-06-13 ~ 2026-07-22）
- **指标**：ab_fwd60 = fwd60 − β×mkt_fwd60（β调整 60 日超额）；大亏 = ab_fwd60 < −20%
- **边际组检验**：在【不含被测门】的样本上，"新放进来的一批"(A) vs "原门内"(B) 逐年比
  收益与大亏率（防幸存者偏差，见 补充诊断_20261029 §2）
- **整池配对区块 bootstrap**：放宽池 − 现池日均超额差，区块=60 交易日、4000 次、90%CI
- **判定口径**：有效年=两组事件数均≥8；及格线 6/8；放宽成立需【边际组不更差】
- **脚本**：research/yh_relax4.py（v2 修复 `over` 参数被 `**kwargs` 吞掉的 bug 后重跑）

## 2. 结果

### H1 prox 0.95 → 0.90：**拒绝**（关键证据在 DOWN 期）

- 边际组（0.90~0.95）n=3499 vs 原门内 n=2172：A−B = **−1.43pp**，收益一致性 4/8、风险 4/8（无一致方向）
- 整池配对：全样本 −0.68pp 含零；**DOWN 期 −1.52pp，CI[−2.81, −0.41] 显著为负**
- 当前正处于 DOWN 周期 → 在现在放宽 prox 是**确定性地变差**

### H2 箱宽 15% → 20%：**强烈拒绝**（四门中证据最强）

- 边际组（15%~20%）n=914：A−B = **−2.48pp**，收益方向 **7/8 年一致更差**
- 风险维度 6/8 年边际组大亏率更高（2022 年 +6.0pp、2025 年 +7.3pp、2026 年 +5.8pp）
- 整池配对：**全样本 −0.76pp 显著为负、CHOP −0.59pp 显著为负、DOWN −1.60pp 显著为负**
- 结论：箱宽是本策略最核心的结构约束之一，放不得

### H3 换手 6% → 7%：**改了等于没改**（门不咬合）

- 边际组（6%~7%）**7 年只有 3 个事件**，逐年全部"样本稀薄"（0/0）
- 整池配对：四个范围差值均 ≈ 0.00pp
- 结论：换手在 6%~7% 之间几乎没有股票，放宽无实际意义；若要真放需到 8%~10% 才有样本，
  那已超出"放宽一点"的范畴，且高换手与本策略低波画像冲突，不再展开

### H4 删除 ret60≤19% 门：**拒绝删除**（复核确认 10-29 结论）

- 边际组（ret60>19%）n=695：A−B = +0.09pp（收益打平），收益一致性 3/8
- **风险一致性 0/8——8 年全部更危险**（2026 年大亏率 19.0% vs 7.1%，差 11.9pp）
- 整池配对：DOWN 期 −0.64pp，CI[−1.17, +0.02] 贴线含零
- 结论与 10-29 完全一致：ret60 是**风险门不是收益门**，删掉等于每年多踩雷

## 3. 裁决汇总

| 假设 | 收益一致性 | 风险一致性 | 整池配对（DOWN） | 裁决 |
|---|---|---|---|---|
| H1 prox→0.90 | 4/8 | 4/8 | **−1.52pp 显著为负** | ❌ 拒绝 |
| H2 箱宽→20% | 7/8 一致更差 | 6/8 更危险 | **−1.60pp 显著为负** | ❌ 强烈拒绝 |
| H3 换手→7% | 0/0（3 事件） | 0/0 | ≈0 | ⚪ 改了等于没改，不动 |
| H4 删 ret60 | 3/8 | **0/8 全更危险** | −0.64pp 贴线 | ❌ 拒绝删除 |

**总裁决：四门全部维持现值（0.95 / 15% / 6% / ret60≤19%）。**

## 4. 对三只票的最终解释

| 票 | 卡点 | 实证含义 |
|---|---|---|
| 国电电力 600795 | 仅卡门①（prox 0.925，差 2.5pp） | 放宽门①在 DOWN 期显著为负 → 不放；它若横盘数日会自然进门 |
| 百济神州 688235 | 卡门①（0.910）+ 门②（箱宽 18.8%） | 需同时放两道门，双双被拒 |
| 昭衍新药 603127 | 卡门①（0.864）+ 门②（31.2%）+ 门④（6.47%） | 高波动趋势票，与本策略"低波贴高"画像本质冲突，任何档位都进不来 |

**核心结论**：池子"全是防御票"不是漏斗出错，是 DOWN 期 + 门① 的设计使然。
用户主观偏好的三只票属于"强势但波动大"的另一画像，与本策略互补而非互替。
若确实想覆盖这类票，正确做法是另建策略线（如趋势跟踪），而不是放宽本策略的结构门。
