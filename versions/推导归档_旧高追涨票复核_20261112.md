# 推导归档｜为什么 11-12 主池里有新产业和中炬高新

- 日期：2026-11-12（收盘实盘后）
- 触发：用户质疑「为什么会有新产业和中炬高新」
- 框架：v2.6（prox≥0.88 / VCP / 额≥2亿 / R / C / H / F≤35日 / 行业黑名单；N 与 ret60 已删、基本面全删）
- 脚本：`research/yh_doubletop_recheck.py` → `output/doubletop_recheck_20261112.txt`
- 数据：通达信前复权日线（本地 `cache/kline_320.pkl`、`cache/panel_320_0.pkl`）+ 全样本事件 `cache/events_fixed.pkl`（150.2 万）

## 1. 结论速览

两只票**不是门失效，而是九道门按定义正常工作**。它们都属于「一年前旧高点附近的收敛平台」，
而能干净区分它们的 N 门（年高新鲜度）与 ret60 门，都是本项目按用户指令或全样本实证**主动删除**的：

| 删除的门 | 何时删 | 当时依据 |
|---|---|---|
| `ret60`（60日涨幅） | v2.2 | 用户指令「ret60 这个 60 日涨幅也删掉」 |
| `N`（hi250_ago≤60日） | v2.5 | 16 组合矩阵 + 40~250 日阈值扫描：ab 非单调、大亏率随放宽单调下降，判定无解释力 |

同时还有一个更根本的反直觉事实：**德尔 10-23 的「理想形态」在追涨维度上比新产业更极端**，
所以任何「别追涨 / 必须贴近箱顶」的修补条件都会先误杀德尔。

**新产业**：7 月低点 39.45 → 11-03 高点 64.00（+62%），10-23 起三周 +13% 急拉，
随后在 58.57~64.00 横盘 10 天。年高 64.98 是 **242 个交易日前**留下的，现价是在回补一年前的套牢区，
属于典型「旧高双顶 + 急涨后高位整理」。九道门里 R 只看近 10 日（−2.1%，过），
ret20/ret60 门已删，所以「前面涨了一大波」完全不被检验。

**中炬高新**：全年在 16.46~21.29 宽幅震荡，ma60 18.34 ≈ ma120 18.35（横盘，非下跌趋势），
11-06 冲到 20.30 后连续 4 日回落到 18.99（−6.5%）。年高 21.29 是 138 日前的。
它是「低位宽箱体内反弹后回踩」，不是「逼近箱顶待突破」。
H 门只看 `hi10≥hi30×0.95`（10 日内摸过箱顶即可），不看收盘位置，所以冲高回落仍算「箱顶不塌」。

**同一问题不止两只**：惠泰医疗 hi250_ago=248 日，也是旧高双顶，只是分数高（52.4）没被质疑。

- **所有 bootstrap 差值均含零**（29 个 60 日区块），逐年也不一致 → 加任一门都不是显著的收益优化。
- 恢复 N 会剔掉 A 中 22.0% 的事件，四口径**全面小幅变差**，与 v2.5 删 N 的结论一致（这次是在 F 门存在的前提下复核）。
- E（收盘必须贴近箱顶）是唯一四口径都改善的配置，但 **CI 含零**，且会直接误杀德尔 10-23（−9.9%）与金石亚药（−6.8%）。
- ret20/ret60/箱顶门同样误杀德尔（ret20 +14.2%、ret60 +62.2%、距箱顶 −9.9%），与「必须能选出德尔」的核心约束冲突。

## 4. 若恢复 N 门，11-12 主池会怎样

主池 **5 → 2 只**：只剩伊利股份（hi250_ago 8 日）、金石亚药（25 日）。
被剔：新产业 242、中炬高新 138、惠泰医疗 248。德尔 10-23（14 日）不受影响。

代价：全样本 ab +1.14%→+0.99%、日均 7.2→6.1，差值 CI 含零（统计上不显著，但也没有增益）；
实盘票量从 5 只压到 2 只，分散度下降。这是**纯语义取舍**，不是收益优化。

## 5. 建议

**默认不改 v2.6**。理由：① 两只票形态确实「不是启动前平台」，但指标上完全合规，
是删 N / 删 ret60 的预期结果而非 bug；② 恢复 N 能把它们剔掉且不误杀德尔，但全样本无增益、
实盘票量减半；③ 其他「别追涨」类条件都会先误杀德尔。

若用户更看重名单语义纯度而非票量，恢复 N 是**唯一干净且低代价**的选项（v2.7）。
另可做「只加标注不改门」：在输出表加 `hi250_ago` 分组标签（新高新鲜 / 旧高双顶），
把判断权留给人，零副作用。

### 6.4 结论

1. **「旧高双顶」不是风险标签，反而是略优的一组**。用 N 门去剔它，是用一个
   与后续收益无单调关系的形态标签做筛选，会同时剔掉中际旭创、中国中免这类主升浪起点。
2. **好/坏案例在事件日的技术指标上不可分**。真正决定 60 日结局的是产业催化与市场环境，
   这正是所有修补门 bootstrap 含零、逐年不一致的根本原因。
3. 对 11-12 的新产业、中炬高新：它们属于统计上略优的旧高组；新产业额外叠加
   「急涨后高位整理」（ret20 +14.4%），但德尔 10-23 的 ret20 +14.2% / ret60 +62.2%
   更极端，同样不能据此剔除。
4. **建议维持 v2.6 不动**（较上一轮更坚定）。若要提升名单可读性，采用零副作用的
   `hi250_ago` 分组标注，而非新增门槛。

> ⚠️ 案例是按【已知结果】挑的极值，非随机样本，仅供形态语义判断，不可用于估计胜率；
> 收益结论一律以上表全样本分布为准。
